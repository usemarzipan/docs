# Screenshots to create

Every new or rewritten page uses placeholder image URLs following the existing convention:

```
https://marzipan-cloud.b-cdn.net/0/docs/<area>/<name>.png
```

The placeholders will render as broken images until you upload a file to the matching path on the CDN (`marzipan-cloud.b-cdn.net/0/docs/...`). Below is the full list of **new** screenshots to capture, grouped by area, with what each should show. Existing order screenshots (`orders/orders-table.png`, `order-filter.png`, `order-export.png`, `create-order.png`, `order-detail-overview.png`, `order-fulfil.png`, `order-fulfil-modal.png`, `order-fulfilled.png`) are reused as-is and don't need recreating.

**Tip:** capture at a consistent width, in a clean demo store with realistic wine data, light theme, and no personal customer details.
