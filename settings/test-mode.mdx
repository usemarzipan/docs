---
title: 'Test Mode'
description: 'Test your store without processing real payments.'
---

Test mode lets you test the complete shopping experience, including checkout and payment, without processing real charges. When enabled, all payment gateways automatically switch to their test/sandbox credentials.

## How It Works

Navigate to **Settings > Test Mode**, under **Developer**, to find the **Enable Test Mode** switch.

When test mode is **on**:
- All payment gateways use their test/sandbox credentials
- All integrations switch to their test/sandbox mode, not just payment gateways
- Orders are processed normally but payments go through sandbox environments
- You can test the full checkout flow with test card numbers
- All other store functionality (inventory, fulfilment) works as normal

Two more switches control what test mode does outside Marzipan:

- **Send Emails** - turn it off to have emails logged but not sent while test mode is on
- **Sync Marketing** - turn it off to skip Mailchimp syncs while test mode is on. Changes coming in from Mailchimp are still processed.

<Note>
For Stripe, test mode uses a **separate test Connect account** rather than stored test API keys. Connect your test account in **Settings > Payments** alongside your live one.
</Note>

## Going live

Turning test mode off takes your store live. A **Switch to Live Mode?** confirmation reminds you to set up live credentials first, and names any payment provider that has none connected yet, since you won't be able to take real payments through it until you do. Click **Go Live** to confirm.

When you go live:
- All payment gateways switch to their live credentials
- All integrations are set to live mode
- Real payments are processed
- Your customers are kept, but anything they picked up in testing is cleared: test payment cards, test Stripe customer records, their stats and their test activity

<Warning>
Going live is **one-way**. Once your store is live, test mode can't be turned back on, so real customers can never be sent through sandbox payments. Finish testing before you go live.
</Warning>

## Setting Up Test Credentials

Set up test access for each gateway you use:

### Stripe
Connect a **separate test Connect account** in **Settings > Payments**. Stripe test mode uses this connected account rather than stored test API keys, so there are no keys to copy across.

### PayPal
Enter your PayPal sandbox client ID and secret from the [PayPal Developer Dashboard](https://developer.paypal.com/dashboard/applications/sandbox).

### PayFast
Enter your PayFast sandbox merchant ID, merchant key, and passphrase from the [PayFast Sandbox](https://sandbox.payfast.co.za).

## Test Card Numbers

When using Stripe in test mode, you can use these test card numbers:

| Card | Number |
|------|--------|
| Visa (success) | `4242 4242 4242 4242` |
| Visa (declined) | `4000 0000 0000 0002` |
| 3D Secure | `4000 0027 6000 3184` |

Use any future expiry date and any 3-digit CVC.

## Clearing Test Data

Testing your store creates real records that you won't want cluttering your data when you go live. The **Test Data** section lists what was created in test mode, and **Purge Test Data** removes it:

- Orders, along with their payments, items and shipments
- Carts
- Subscriptions

Customers and products are not affected. The confirmation lists exactly what will be removed before you click **Purge**, and a purge can't be undone.

Run a purge once you've finished testing and before you open your store to real customers.
